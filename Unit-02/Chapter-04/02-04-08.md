# Unit 2 Chapter 4 Question 8 - Valid Triangles

Triangles are one of the strongest shapes used in construction, but not just any three lengths can be joined together to form one. If two of the sides are too short to reach across the third, the shape simply can't close.

Write a program that takes the lengths of three sides, $S_1$, $S_2$, and $S_3$, and determines whether they can form a triangle. If they can, classify the triangle by its side lengths.

Three lengths can form a triangle only if the sum of any two of the sides is *greater than* the length of the third side.

## Input Specification

The input consists of three lines. Each line is a non-negative integer, which represents a side length of a triangle.

## Output Specification

Output the type of triangle formed by the three sides.

- If the three lengths cannot form a triangle, output `not a triangle`.
- If all three sides are equal in length, output `equilateral`.
- If exactly two sides are equal in length, output `isosceles`.
- If all three sides are different in length, output `scalene`.

## Sample Input 1

```
3
4
5
```

## Sample Output 1

```
scalene
```

## Explanation for Sample Output 1

As the sum of any two sides is greater than the third side, and given that no side lengths are 0, the triangle is valid. The triangle is `scalene` as no two side lengths are the same.

## Sample Input 2

```
2
2
5
```

## Sample Output 2

```
not a triangle
```


## Explanation for Sample Output 2

As the sum of sides $S_1$ and $S_2$ are not greater than side $S_3$, the shape the three sides form is not a valid triangle.
