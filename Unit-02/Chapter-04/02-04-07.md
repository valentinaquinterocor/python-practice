# Unit 2 Chapter 4 Question 7 - Leap Year

A calendar year is normally 365 days long, but it actually takes the Earth slightly longer than that to orbit the Sun. To keep our calendars lined up with the seasons, an extra day (February 29th) is added to certain years. These years are called leap years.

Write a program that determines whether a given year is a leap year.

A year is a leap year if it is divisible by 4, with one exception: years divisible by 100 are *not* leap years, unless they are also divisible by 400.

## Input Specification

The input consists of a single line containing one positive integer, the year.

## Output Specification

Output whether or not the given year is a leap year.

- If the year is a leap year, output `leap year`.
- Otherwise, output `not a leap year`.

## Sample Input 1

```
2024
```

## Sample Output 1

```
leap year
```

## Explanation for Sample Output 1

$2024$ is divisible by $4$. Years divisible by $4$ may not always be leap years if they are also divisible by $100$, but $2024$ is not one of those examples.

## Sample Input 2

```
1900
```

## Sample Output 2

```
not a leap year
```

## Explanation for Sample Output 2

$1900$, though divisible by $4$, is not a leap year, as it is divisible by $100$, but not $400$.
